# 🎯 Estudos de Dart

Este repositório contém os códigos desenvolvidos durante as aulas de **Desenvolvimento Mobile** da minha graduação. O objetivo é dominar a linguagem **Dart** como base para o desenvolvimento de aplicativos com Flutter.

## 📚 Tópicos Estudados
O conteúdo está organizado progressivamente conforme a grade da disciplina:

- **📂 Aula 1 / Fundamentos:**
  - Sintaxe básica do Dart.
  - Tipos de variáveis e estruturas de controle.
  
- **📂 Aula 2 / Orientação a Objetos:**
  - Criação de Classes e Objetos.
  - Atributos e Métodos.
  - *Exemplo prático:* Estrutura de classes para personagens (RPG/Jogos).

## 🛠️ Tecnologias
- **Linguagem:** Dart (SDK)
- **IDE:** Visual Studio Code
